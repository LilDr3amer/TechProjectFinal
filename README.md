# Консольная программа для обработки массива с последующей записью в html файл

## Описание
Программа на C++ для ввода и обработки массива целых положительных чисел.
Запрашивает у пользователя количество элементов массива от 1 до 10.
Запрашивает у пользователя элементы массива - целые положительные числа.
Определяет минимальное, максимальное и среднее арифметическое значения.
Создает html файл, куда записываются данные массива, результат вычисления, выводится диаграмма минимального, среднего и максимального значений.

## Требования
- Компилятор C++ (g++, MSVC, clang++)
- Стандарт C++11 или выше


## Как работает
1. Программа запрашивает размер массива (только 10).
2. Пользователь вводит 10 положительных целых чисел.
3. Каждый ввод проверяется:

- буквы и символы — отклоняются;

- отрицательные и ноль — отклоняются;

- дробные числа — отклоняются.

4. В конце выводятся:

- минимальное значение;

- максимальное значение;

- среднее арифметическое (с двумя знаками после запятой).

5. Создается и автоматически открывается html файл с данными.

## Как собрать
g++ TechProjectFinal.cpp -o program

## Как запустить
./program

## Как запустить в Visual Studio
1. Открыть TechProjectFinal.cpp в Visual Studio
2. Нажать F5 (или Ctrl+F5 для запуска без отладки)
